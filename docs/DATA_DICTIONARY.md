# Data Dictionary — Smart Upgrade Dataset

All data is synthetic, generated by `data/generate_local.py` (pure Python stdlib, `seed=42`, reproducible). Three raw source files model Lumera Books production streams. The data is intentionally imperfect — handling that is part of the case study.

Date basis: a rolling 180-day window ending on the generation date.

## subscriptions.csv — one row per business (10,000 rows)

| Column | Type | Description |
|---|---|---|
| business_id | string | Primary key, e.g. `BUS-000123` |
| business_name | string | Synthetic company name |
| plan_tier | string | `Free` (~55%), `Mid` (~30%), `Premium` (~15%) |
| seats | int | Licensed users; scales with tier |
| mrr | double | Monthly recurring revenue (0 for Free) |
| signup_date | date | Account creation date (30–1110 days ago) |
| renewal_date | date | Next renewal anniversary |
| is_power_user_seed | boolean | **Ground truth for grading — tell candidates to ignore.** True for the seeded Power-User cohort |

## transactions.csv — monthly financial snapshot per business (60,000 rows)

| Column | Type | Description |
|---|---|---|
| business_id | string | FK → subscriptions |
| txn_month | date | First of month (6 monthly snapshots) |
| invoice_count | int | Invoices issued that month; elevated for Power Users |
| payroll_runs | int | Payroll runs that month (0 for most Free) |
| revenue | double | Business revenue processed that month |

## telemetry_events.csv(.gz) — one row per clickstream event (~785,000 rows)

| Column | Type | Description |
|---|---|---|
| event_id | string | Event id, e.g. `EVT-BUS-000123-00042` (NOT unique — see duplicates) |
| business_id | string | FK → subscriptions |
| user_id | string | e.g. `BUS-000123-U3`; ~1% null |
| event_ts | timestamp | `yyyy-MM-dd HH:mm:ss`; naturally out-of-order |
| session_id | string | `SESS-<business>-<yyyymmdd>-<n>` |
| event_type | string | `login`, `page_load`, `click`, `feature_use`, `logout`, or `error` |
| page | string | `dashboard`, `invoices`, `payroll`, `reports`, `expenses`, `settings`, `upgrade` |
| error_code | string | Only when `event_type='error'`, else empty |
| device | string | `web-*` / `mobile-*`; ~2% null, ~1% malformed (`unknown/??`) |

## Seeded signal — the cohort to discover

~**4.9% of all businesses** are Mid-tier **Power Users**. Relative to others they show:
- **Higher invoice volume and revenue** (≈2.5× invoices, ≈1.8× revenue).
- **A friction error signature:** ≈18% of their events are errors (vs. ≈4% for others), biased toward `LIMIT_EXCEEDED` and `FEATURE_LOCKED` — the "outgrown their plan" signal. Non-power users' errors skew to generic `TIMEOUT` / `VALIDATION` / `SERVER_500`.

The candidate should surface this cohort and the friction funnel **from behavior**, then validate against `is_power_user_seed`.

## Built-in data-quality challenges (Silver-layer test)

| Issue | Where | Approx. rate |
|---|---|---|
| Exact duplicate rows | telemetry_events | ~11,500 rows (~1.5%) |
| Null `user_id` | telemetry_events | ~1% |
| Null `device` | telemetry_events | ~2% |
| Malformed `device` (`unknown/??`) | telemetry_events | ~1% |
| Out-of-order timestamps | telemetry_events | inherent (random within window) |
